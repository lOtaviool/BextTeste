# Bext Teste Vue

## Sobre o projeto

Esta aplicação consiste em um case teste da Bext com o objetivo de apresentar conhecimentos e experiências no desenvolvimento front-end de uma aplicação.

## Tecnologias utilizadas

- Vue 3
- JavaScript
- Vite
- Pínia
- Axios
- Tailwind CSS
- ESLint
- Prettier
- JSON Server

## Login

Como esta é uma aplicação de teste o Login é composto por email e senha aleatórios, porém, é necessário que os dados cumpram as normas de formatação:

Email - Deve conter o formato correto com o '@' e o '.com', por exemplo: luisteste@teste.com.


Senha - Fica a critério do usuário.

## Pré-requisitos

Antes de executar o projeto, certifique-se de possuir instalado em sua máquina:

- Node.js (versão 18 ou superior recomendada)
- npm ou Yarn
- Git

## Instalação

Clone o repositório:

```bash
git clone https://github.com/lOtaviool/BextTeste.git
```

Acesse a pasta do projeto:

```bash
cd BextTeste
```

Instale as dependências:

Com npm:

```bash
npm install
```

Ou utilizando Yarn:

```bash
yarn install
```

## Executando a aplicação

### Front-end

Para iniciar a aplicação Vue:

Com npm:

```bash
npm run dev
```

Ou com Yarn:

```bash
yarn dev
```

Após iniciar o projeto, a aplicação ficará disponível em:

```
http://localhost:5173
```

## Executando o servidor Mock

Este projeto utiliza o JSON Server para simular uma API REST.

Para iniciar o servidor:

Com npm:

```bash
npm run mock:server
```

Ou utilizando Yarn:

```bash
yarn mock:server
```

Por padrão, a API estará disponível em:

```
http://localhost:3000
```
